## What Is DisplayCAL

DisplayCAL is a measurement helper for one screen at a time. DisplayCAL monitor profile is the file other programs use to understand that screen. DisplayCAL white point and DisplayCAL tone curve are choices you make before the meter runs: how white should look, and how the grays should step. A student editing a class photo, or someone printing a few pictures at home, can keep those choices written down.

DisplayCAL verification report is the later check. It does not replace the profile. It tells you whether the profile still describes the screen. DisplayCAL gamut view is the picture of the volume, useful when a laptop panel is smaller than a photo space you hoped to judge. Together, DisplayCAL white point, DisplayCAL tone curve, and DisplayCAL gamut view explain the screen in plain pieces.

Start with a warm panel and a dark-enough room. Build DisplayCAL monitor profile once, read DisplayCAL verification report, and glance at DisplayCAL gamut view before a color-sensitive hour. Repeat the measurement when weeks have passed or the screen looks different. That habit fits home study and small photo jobs.
